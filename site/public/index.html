Irrigación Bot

Nombre de la aplicación: Irrigación Bot

Irrigación Bot es una aplicación de la Jefatura de Zona de Riego de Malargüe (Mendoza, Argentina). Esta página es pública: no hace falta iniciar sesión para leerla.

Abrir Irrigación Bot Política de privacidad

Propósito de la aplicación

El propósito de Irrigación Bot es ayudar al personal autorizado de la Jefatura de Zona de Riego a hacer su trabajo diario: consultar información operativa y normativa, recuperar documentos internos, y guardar notas de contexto (de oficina o personales).

También puede, solo si el usuario inicia sesión con Google y lo autoriza, usar Google Calendar, Gmail y Drive para listar o crear eventos, listar o enviar correos, y buscar o leer archivos.

Application purpose: Irrigación Bot is a workplace assistant for irrigation staff. It answers questions from internal documents and, with the user’s Google sign-in and confirmation, can read or create Calendar events, list or send Gmail messages, and search or read Drive files.

Funcionalidad de Irrigación Bot

  • Chat de consulta sobre operación hídrica, normativa y documentos que la oficina ya cargó.
  • Guardar texto como contexto compartido de irrigación o como contexto personal del usuario.
  • Subir documentos de oficina para indexarlos y poder preguntar sobre ellos.
  • Google Calendar: ver la agenda y crear eventos, con confirmación en pantalla antes de crear.
  • Gmail: listar correos recientes y enviar un mail, con confirmación en pantalla antes de enviar.
  • Google Drive: buscar y leer archivos; opcionalmente indexar un archivo como contexto, si el usuario lo pide.

Por qué Irrigación Bot pide datos de Google

Irrigación Bot solicita acceso a la cuenta de Google del usuario únicamente para las funciones que esa persona pide en el chat. No usamos esos datos para publicidad ni para entrenar modelos de terceros.

  • Identidad (nombre, correo, foto): para iniciar sesión y saber qué contexto personal y tokens corresponden a cada persona.
  • Calendar: para mostrar eventos próximos y crear un evento cuando el usuario lo pide.
  • Gmail: para listar o resumir correos y enviar un mensaje cuando el usuario lo pide y confirma.
  • Drive (solo lectura): para buscar y leer archivos que el usuario indica, o indexarlos como contexto si lo pide.

Crear un evento o enviar un correo requiere un paso extra de Autorizar / Cancelar en la propia aplicación.
