Irrigación Bot

Application name: Irrigación Bot

Irrigación Bot is an application operated by the Jefatura de Zona de Riego de Malargüe (Irrigation District Office, Malargüe, Mendoza, Argentina). This homepage is public. You do not need to sign in to read it.

Open Irrigación Bot Privacy Policy

Application purpose

The purpose of Irrigación Bot is to help authorized staff of the Irrigation District Office with daily work: answer operational and regulatory questions, retrieve internal documents, and save office-wide or personal notes as context for the assistant.

Irrigación Bot can also use Google Calendar, Gmail and Google Drive only when the user signs in with Google and authorizes those actions.

What Irrigación Bot does

  • Chat Q&A about irrigation operations, regulations, and documents the office has already uploaded.
  • Save text as shared irrigation context or as personal context for the signed-in user.
  • Upload office documents so staff can ask questions about them.
  • Google Calendar: list upcoming events and create an event, with an on-screen Authorize / Cancel step before creating.
  • Gmail: list recent messages and send email, with an on-screen Authorize / Cancel step before sending.
  • Google Drive (read-only): search and read files; optionally index a file as context if the user asks.

Why Irrigación Bot requests Google user data

Irrigación Bot requests Google account access only to provide the features the signed-in user asks for in the chat. We do not use this data for advertising or to train third-party AI models.

  • Identity (name, email, profile photo): to sign the user in and associate personal context and OAuth tokens with that person.
  • Calendar: to show upcoming events and create an event when the user asks.
  • Gmail: to list or summarize recent mail and send a message when the user asks and confirms.
  • Drive (read-only): to search and read files the user points to, or index them as context if requested.

Creating a calendar event or sending email requires an extra Authorize / Cancel confirmation inside Irrigación Bot.
